# Sahaya - Emergency SOS App 🚨

An Android application designed to help physically disabled individuals in emergency situations.

## Features
- SOS alert via SMS 📩
- Live location sharing 📍
- Emergency contact system ☎️
- User profile management 👤

## Tech Used
- Java (Android)
- Firebase Realtime Database
- Location Services

## Future Improvements
- Shake detection 📳
- Voice trigger 🎤
- Smart login system 🔐
